## Назначение

Команда `/simplegen.init` выполняет (пере)инициализацию инструментов автоматизации:

- Обновляет экспорты `platform/` и `sa/`
- Обновляет DSL продукта (`<product>/domain/`)
- Создаёт/обновляет `AGENTS.md`
- Сидирует `<product>/docs/index.md` (если его нет) и обновляет `<product>/docs/theme.puml` — общую тему диаграмм
- Генерирует AI-артефакты в `.claude/` (skills и agents, канон) и `.opencode/` (rules, commands, agent)
- Использует CLI `simplegen` (npm-пакет) для выгрузки данных со стенда

## Алгоритм работы

### Шаг 1: Определить продукт(ы)

1. Если пользователь указал имена продуктов (через запятую) — использовать их
2. Если не указал — определить по существующим продуктам или запросить у пользователя. Каталог продукта — это slug в нижнем регистре (`itsm/`, `service-desk/`), а CLI нужно точное имя приложения: бери его из третьей строки `<product>/AGENTS.md` (`` `<product>/` — продукт **<Имя>**. ``)

### Шаг 1.5: Сохранить контекст задач (⚠️ ВАЖНО)

Активная фича хранится в `SIMPLEGEN_ACTIVE_FEATURE` (`.env`); `.env` в `.gitignore`, init его не трогает — контекст переживает переинициализацию автоматически.

**⚠️ CLI `simplegen init` НЕ должен трогать `tasks/`.**
Если CLI всё же затирает `<product>/<feature_path>/simplegen.json` (с `initial_commit_sha`) — восстановить эти данные вручную.

### Шаг 2: Выполнить инициализацию

Выполни в терминале: `simplegen init <product1> <product2> ...`

Каждый продукт — отдельный аргумент; имя с пробелами бери в кавычки: `simplegen init SDLC "Service Desk"`. Имя должно в точности (с учётом регистра) совпадать с `name` приложения на стенде. Если CLI ответил `No application "…" on the instance`, возьми правильное имя из подсказки (`did you mean`) или из списка приложений в ошибке и повтори команду.
Если продукты не указаны — выполняется инициализация только `platform/` и `sa/` (без продуктовых каталогов).

CLI автоматически (для каждого указанного продукта):
- Подключится к стенду SimpleOne и проверит доступность API
- Выгрузит и создаст/перезатрёт `platform/`, `sa/`
- Выгрузит и создаст/перезатрёт `<product>/domain/`
- Создаст/обновит `<product>/AGENTS.md`
- Создаст/обновит AI-артефакты: `.claude/skills/`, `.claude/agents/` (канон) и `.opencode/` (`rules/`, `commands/`, `agents/`, `opencode.json`)
- Создаст/обновит `simpleone-api.d.ts`, индекс сигнатур `api-index/`, `jsconfig.json`
- Дополнит корневой `.gitignore` (существующие строки сохраняются)
- Запишет состояние пакета в `.simplegen/state.json` (версия, хеши dist и templates)

## Особые случаи

### Нет подключения к стенду

```markdown
⚠️ Не удалось подключиться к стенду SimpleOne.

Проверьте:
- Настройки подключения
- Доступность сети
- Авторизацию

→ Повторите `/simplegen.init` после устранения проблемы
```

### Первичная инициализация

При отсутствии каталогов продуктов:

- Запросить имена продуктов — точные `name` приложений на стенде (например, `ITSM`, `Service Desk`)
- Создать структуру каталогов для каждого указанного продукта
- Сгенерировать базовый `AGENTS.md` для каждого продукта
